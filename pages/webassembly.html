From the terminal to the browser

WebAssembly

If you saw Blackjack and dungeon-cli on my Projects page, those started as terminal games. I wanted to make them easier to try, so I brought them to the browser using WebAssembly.

WebAssembly lets the browser run compiled code. That means I can reuse the game logic instead of rewriting it in JavaScript, and you can play without installing anything.
